# School Maintenance Reporting System

A Laravel-based web application for reporting and managing school maintenance issues.

## Project Description

The School Maintenance Reporting System allows students/users to report maintenance issues within the school and allows maintenance staff to manage and monitor submitted reports.

## Main Features

- Home Page
- Report Maintenance Issue
- View Reports
- Report Status
  - Pending
  - In Progress
  - Resolved
- Delete Report
- Basic Search and Filter

## User Roles

### Student/User
- Access the home page
- Submit maintenance reports
- View submitted reports
- Search and filter reports

### Maintenance Staff
- View maintenance reports
- Update report status
- Delete reports

## Technologies Used

- Laravel
- PHP
- MySQL
- Blade
- HTML
- CSS
- JavaScript
- Laragon
